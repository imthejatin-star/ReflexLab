# ReflexLab — Reaction Trainer

A simple touch-friendly reaction test.

## How it works
- Start a 20-round test.
- Wait for a green target to appear.
- Tap the target as quickly as you can.
- The target appears at a different position after a random delay.
- Tapping before the target appears ends the test as an early tap.
- The app records successful response times, session average, best response and recent sessions on the device.

## Open
Enable GitHub Pages in **Settings → Pages → Build and deployment → GitHub Actions**. The Pages workflow deploys on pushes to `main`.

## Android
The Android Actions workflow builds a debug APK. Open the latest successful Android build and download its artifact.

## Notes
This is a simple screen-based practice tool, not a medical test. Touch latency, refresh rate and device performance affect recorded times. Take breaks if your eyes feel tired.
