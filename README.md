# ReflexLab

A daily reflex and visual-response training app designed for short, varied sessions. Includes reaction, choice, peripheral-awareness and coordination exercises, progress history, and offline-first local storage.

## Run
Open `index.html` in a browser, or enable GitHub Pages from Settings → Pages → Deploy from branch → `main` / root.

## Training note
This app measures performance on its own exercises. Improvement in game scores does not guarantee improved real-world reflexes or sports performance. Stop if you feel eye strain, dizziness or discomfort. Keep sessions short and take breaks.
